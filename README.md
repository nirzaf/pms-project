# O'Reilly's Bungalow - Property Management System

## About
This project is a property management system for O'Reilly's Bungalow resort, featuring a modern web interface built with React, TypeScript, and Tailwind CSS.

## Brand Guidelines

### Logo Details

#### Font Styles
- **O'Reilly's**: Aerokids (Regular)
- **BUNGALOW**: Nulshockrg (Bold)

#### Color Palette
- Navy Blue: `#050063`
- Gold: `#DEA401`
- Black: `#000000`
- White: `#FFFFFF`

### Typography
The website uses the following fonts:
- **Pacifico**: Used for stylized headings
- **Quicksand**: Used for body text and UI elements (weights: 300, 400, 500, 600, 700)

## Development

### Technologies Used
- React with TypeScript
- Vite as build tool
- Tailwind CSS for styling
- Three.js for 3D elements
- React Spring for animations

### Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Features
- Interactive 3D background elements
- Animated UI components
- Responsive design for all device sizes
- Booking management system
- Resort amenities showcase
